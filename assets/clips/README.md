# 🎬 Put yourself in the game

Drop video clips of yourself in **this folder** and the game plays them instead of the cartoon actors —
in cutscenes (the "facecam" bubble next to the subtitles) and on the developer's TV in the main menu.

## How it works

1. Record yourself saying a line (phone, webcam, anything). Keep it short — a few seconds.
2. Name the file after the line's id from the tables below, for example **`guard05.mp4`**.
3. Put it in this folder: `assets/clips/guard05.mp4`
4. Refresh the game. Done! The subtitles still show, and the game waits for your clip to finish.

* Formats: **`.mp4`** works everywhere. `.webm` and `.mov` work in most browsers too.
* Square-ish or vertical videos look best (the facecam crops to a square).
* You only need the lines you want — any missing line uses the cartoon + voice.

### Photos instead of videos

Don't want to film every line? Add a photo and it becomes your face whenever there's no video:

| File | Who |
|---|---|
| `guard.png` (or `.jpg` / `.webp`) | the security guard |
| `dev.png` | the developer on the menu TV |
| `aaron.png` | Aaron |

### No files? Use the Clip Studio

The main menu has a **🎬 CLIP STUDIO** button. It lets you record each line with your webcam (or upload a
video) right inside the game. Those recordings are saved in your browser only — press **⬇** next to a
recording to download it with the correct file name, then put it in this folder so everyone gets it.
